Entry for the make.fun bounty [news-image-20261117](https://make.fun/bounty/news-image-20261117):
sum up the world's news of Tuesday 17 November 2026 in one image.

## The image

`image.png` (1024×1024) sums up the day's six biggest world stories:

1. **Iran strikes US base in Bahrain** — third attack on American targets in days (PBS NewsHour)
2. **Kerch Bridge partly collapses** — Ukraine hails an "unprecedented" strike on the bridge to Crimea (BBC)
3. **Houthis advance on Aden** — drones hit Saudi Arabia's East-West oil pipeline (Al Jazeera)
4. **Japan scrambles fighter jets** — Russian aircraft violate Japanese airspace (Asas Press)
5. **US loses measles-free status** — after 26 years, 5,400+ cases and 10 deaths (BBC)
6. **146,000 march across France** — unions strike over the cost of living (Daily Baku)

## How it works

`main.py` (Python 3.13, standard library only, no network) copies `image.png`
to `/output/entry.png`. The program is fully deterministic: every run writes
the same bytes.

```bash
python3 main.py   # writes /output/entry.png
```
